# Roadmap

This roadmap is a set of candidate tasks, not a claim that they are already completed.

- [x] Document a generic six-channel input schema.
- [x] Implement a transparent progress-conditioned GPR baseline.
- [x] Separate model fitting, residual-scale fitting, and conformal calibration.
- [x] Add synthetic-only data generation and basic unit tests.
- [ ] Add global-threshold and median/MAD-per-progress baselines.
- [x] Add exact Clopper-Pearson confidence intervals for FAR and POD.
- [ ] Add day-block bootstrap evaluation for repeated industrial cycles.
- [ ] Add optional comparison adapters for Isolation Forest, LOF, and One-Class SVM.
- [ ] Add an offline replay visualization.
- [ ] Validate on an independently authorized, anonymized dataset.
